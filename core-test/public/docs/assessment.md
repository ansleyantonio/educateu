# Assessment Module API Documentation

This documentation has been organized into multiple files for better navigation and maintainability:

## Assessment Management APIs
- [**Assessment Basics**](assessment-basics.md) - Core assessment operations (Create, Get All, Get by ID, Update, Update Status, Update Quiz Question, Update Assignment Question, Delete)
- [**Awarding Bodies**](assessment-awarding-bodies.md) - Awarding body management for assessments
- [**Quiz Questions**](assessment-quizzes.md) - Quiz question operations (Create, Update, Get, Delete, Index management)
- [**Assignment Questions**](assessment-assignments.md) - Assignment question operations (Create, Update, Get, Delete, Index management)
- [**Rubrics**](assessment-rubrics.md) - Rubric management for assignment evaluations

## Rubric Template Management APIs
- [**Rubric Templates**](rubric.md) - Standalone rubric template operations (Create, Update, Get, Delete, Index management)

Each file contains detailed documentation for the respective API group, including endpoints, request/response formats, examples, and error handling.
