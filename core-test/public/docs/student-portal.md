# Student Portal API Documentation

This documentation has been organized into multiple files for better navigation and maintainability:

## Student Portal APIs

- [**Dashboard APIs**](student-portal-dashboard.md) - Core dashboard operations (Get Courses, Get Upcoming Assessments, Create Support Requests, Get FAQs)
- [**Learning Courses APIs**](student-portal-learning-courses.md) - Course management operations (Get Course Details, Get Modules by Semester, Get Module Contents, Create/Get Lesson Notes)
- [**Assessment APIs**](student-portal-assessment.md) - Assessment operations (Get All Student Assessments, Get Assessment Questions)
- [**Grades APIs**](student-portal-grades.md) - Grade management operations (Get All Grades)
- [**Discussion Forum APIs**](student-portal-discussion-forum.md) - Discussion forum operations (Create/Get/Update/Delete Discussion Threads, Create/Get/Update/Delete Comments)
- [**Upload APIs**](student-portal-upload.md) - File upload and download operations (Upload File, Download File)

Each file contains detailed documentation for the respective API group, including endpoints, request/response formats, examples, and error handling.
